# Plan: Port AeroTube Flutter App from Windows to Android

## Overview
The current AeroTube app is a Flutter application optimized for Windows, using yt-dlp and ffmpeg executables for YouTube downloading. To port it to Android while maintaining "flawless" performance, we need to replace platform-specific dependencies with cross-platform Flutter plugins and handle Android-specific requirements like permissions and background processing.

## Current App Analysis
- **Framework**: Flutter (cross-platform by design)
- **Download Engine**: yt-dlp executable (Windows-specific)
- **Media Processing**: ffmpeg executable (Windows-specific)
- **Authentication**: webview_windows (Windows-specific)
- **Notifications**: local_notifier (Windows-specific)
- **Storage**: Uses path_provider, shared_preferences, hive (cross-platform)
- **Existing Dart Library**: youtube_explode_dart (already in pubspec, can be leveraged for Android)

## Proposed Solution
Switch to pure Dart/native plugin architecture for Android:
- Use `youtube_explode_dart` (already available) for YouTube operations
- Use `ffmpeg_kit_flutter_new` for media processing
- Use `flutter_web_auth_2` for authentication
- Use `flutter_local_notifications` for notifications
- Add Android permissions and foreground service for downloads

## Implementation Steps

### 1. Update Dependencies (pubspec.yaml)
**Remove Windows-specific packages:**
- `webview_windows`
- `local_notifier`

**Add Android-compatible packages:**
- `ffmpeg_kit_flutter_new: ^6.0.3` (for media processing)
- `flutter_web_auth_2: ^3.0.0` (for authentication)
- `flutter_local_notifications: ^17.0.0` (for notifications)
- `permission_handler: ^11.0.0` (for runtime permissions)

**Update existing packages if needed:**
- Ensure `youtube_explode_dart` is up-to-date
- Add Android-specific launcher icons configuration

### 2. Android Configuration
**Update android/app/src/main/AndroidManifest.xml:**
- Add internet permission: `<uses-permission android:name="android.permission.INTERNET" />`
- Add storage permissions: `<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />` and `<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />`
- Add notification permission (API 33+): `<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />`
- Add foreground service permission: `<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />`
- Configure foreground service for downloads

**Update android/app/build.gradle:**
- Set minimum SDK to 21 (Android 5.0)
- Configure ABI splits if using full ffmpeg_kit (armeabi-v7a, arm64-v8a, x86_64)

### 3. Service Refactoring
**Create platform-specific service implementations:**

**YtdlpService Android Version:**
- Add conditional logic to use `youtube_explode_dart` on Android instead of yt-dlp executable
- Implement download logic using YoutubeExplode:
  - Fetch video metadata with `YoutubeExplode.videos.get()`
  - Get streams with `YoutubeExplode.videos.streamsClient.getManifest()`
  - Download streams and merge using ffmpeg_kit
- Handle authentication via flutter_web_auth_2 for age-restricted content

**FfmpegService Android Version:**
- Replace Process.run calls with ffmpeg_kit_flutter_new commands
- Use FFmpegKit.execute() for merging video/audio streams
- Handle progress callbacks and error parsing

**CookieService/WebView Integration:**
- Replace webview_windows with flutter_web_auth_2
- Implement OAuth-style authentication flow for YouTube login
- Store cookies using shared_preferences or secure storage

**NotificationService:**
- Replace local_notifier with flutter_local_notifications
- Configure notification channels for download progress
- Handle runtime permission requests

### 4. UI/UX Adaptations for Mobile
**Touch-friendly interface:**
- Ensure all interactive elements meet Android touch target sizes (48dp minimum)
- Adapt glass-morphism effects for mobile performance
- Optimize layout for various screen sizes using responsive design

**Background processing:**

## Risks and Mitigations
- **Performance**: youtube_explode_dart may be slower than yt-dlp; mitigate with caching and background processing
- **Compatibility**: Some YouTube features may not be available in pure Dart; provide fallback options
- **Permissions**: Android permission changes may affect user experience; implement graceful degradation
- **APK Size**: ffmpeg_kit increases size significantly; consider user segmentation

## Success Criteria
- App builds and runs on Android devices (API 21+)
- Downloads work reliably with equivalent quality to Windows version
- Authentication flow functions properly
- Notifications display correctly
- UI is touch-friendly and responsive
- Battery usage is reasonable for download operations
