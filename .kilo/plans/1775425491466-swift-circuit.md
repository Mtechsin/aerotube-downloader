# Plan: Fix Flutter Layout Error - BoxConstraints forces an infinite height

## Problem Analysis

The error occurs in `mobile_video_configuration_widget.dart:103` where a `Stack` widget with `StackFit.expand` is receiving infinite height constraints.

**Root Cause:**
- `MobileVideoConfigurationWidget` is placed inside a `SingleChildScrollView` (in `mobile_fetch_screen.dart:168`)
- The scroll view provides unbounded (infinite) height constraints to its children
- Stacks with `fit: StackFit.expand` attempt to expand to fill all available space
- When height is infinite, this is impossible → `BoxConstraints(w=379.4, h=Infinity)` is invalid

**Widget tree causing error:**
```
SingleChildScrollView (unbounded height)
  └─ Column
      └─ MobileVideoConfigurationWidget
          └─ Container
              └─ Stack(fit: StackFit.expand) ❌
```

## Solution

Remove `fit: StackFit.expand` from the Stack widgets in `mobile_video_configuration_widget.dart`:

1. **Line 103-104**: Outer Stack
   ```dart
   // Before
   child: Stack(
     fit: StackFit.expand,
     children: [...]
   )
   
   // After
   child: Stack(
     children: [...]
   )
   ```

2. **Line 108-109**: Inner Stack (inside ClipRRect)
   ```dart
   // Before
   child: Stack(
     fit: StackFit.expand,
     children: [...]
   )
   
   // After
   child: Stack(
     children: [...]
   )
   ```

**Why this works:**
- Without `StackFit.expand`, the Stack will size itself based on its children's intrinsic sizes
- This is valid in unbounded height constraints because it doesn't require expanding to infinity
- The visual design remains intact because the Stacks still contain `ClipRRect` and `CachedNetworkImage` that will render correctly

## Implementation Steps

1. Open `lib/ui/widgets/mobile_video_configuration_widget.dart`
2. Remove `fit: StackFit.expand,` from line 104
3. Remove `fit: StackFit.expand,` from line 109
4. Test the app to ensure the layout renders correctly
