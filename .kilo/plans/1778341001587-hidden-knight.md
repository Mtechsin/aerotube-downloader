# Fix: Gradle JVM Crash Due to Insufficient Memory

## Root Cause
The JVM crash (`hs_err_pid27160.log`) shows an out-of-memory error:
```
There is insufficient memory for the Java Runtime Environment to continue.
Native memory allocation (mmap) failed to map 2097152 bytes. Error detail: G1 virtual space
```

The system has **15GB RAM**. The current `gradle.properties` allocates:
- `-Xmx4096M` (4GB heap)
- `-XX:MaxMetaspaceSize=1024M` (1GB metaspace)
- `-XX:ReservedCodeCacheSize=256M` (256MB code cache)
- Plus Gradle daemon, Kotlin compiler, Android build tools, thread stacks (~88 threads)

Total native memory usage far exceeds 15GB, causing the JVM to crash during the build.

## Fix
Reduce JVM memory allocation in `android/gradle.properties` to fit within ~10GB (leaving ~5GB for OS, IDE, and other processes):

- `-Xmx4096M` → `-Xmx2048M` (reduce heap from 4GB to 2GB)
- `-XX:MaxMetaspaceSize=1024M` → `-XX:MaxMetaspaceSize=512M` (reduce metaspace from 1GB to 512MB)
- `-XX:ReservedCodeCacheSize=256M` → `-XX:ReservedCodeCacheSize=128M` (reduce code cache from 256MB to 128MB)

## File to Edit
- `E:\youtube downloader\android\gradle.properties`

## After Fix
Run `flutter run --release` or `cd android && gradlew assembleRelease` again.
If still failing, further reduce `-Xmx` to `1536M` or `1024M`.
